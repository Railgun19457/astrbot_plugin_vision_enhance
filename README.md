# 视觉增强

把模型**看不见的图片**变成模型**能看的图片**。

插件只做两件事，不识别、不修图、不生图。

## 功能

### 1. Markdown 内嵌图还原

QQ 官方机器人等平台会把图片以 Markdown 语法下发，而不是图片消息段：

```
![图片 #380px #330px](https://qqbot.ugcimg.cn/102076836/.../ee184624debd5c7b0eb1580903008f76)
```

平台没有解析它，模型就只能看到一串 URL。插件会把这类文本还原成真正的图片消息。

因为这类 URL **往往没有文件扩展名**，无法靠后缀判断类型。插件采用的方式是实际下载并尝试解码，
解码成功才替换，失败则保留原文。

### 2. 动图抽帧

很多模型无法直接读取动图，只会取第一帧或直接报错。插件会把动图抽成若干张静态图再交给模型，
支持 GIF / WebP / APNG。

两种输出方式（默认拼接大图）：

| 方式 | 效果 |
|---|---|
| 拼接大图 | （默认）所有帧拼成一张，只占一个图片位置，单帧分辨率下降。可在每帧上标注序号 |
| 独立图片 | 每帧作为一张单独的图片，清晰度高，但会占用多个图片位置 |

抽帧规则（按优先级，三个参数可任意组合）：

1. `interval > 0` —— 每隔 N 帧取一帧
2. 否则 `0 < ratio < 1` —— 抽取总帧数的这个比例
3. 否则 —— 均匀抽取 `max_frames` 帧

最终结果会被限制在 `[min_frames, max_frames]` 之内。

### 抽帧说明文本

默认会在抽帧结果后追加一句说明，告知模型这些图来自同一个动图：

```
[Animated image: 24 frames in total, 9 extracted (frames 2, 5, 8, 11, 14, 17, 20, 23, 24).]
```

不开启时，模型只会看到多张图片，可能误以为用户发了多张不同的图，也会丢失帧的先后顺序。

文本内容可自由改写，支持下表占位符（留空则不添加任何说明）：

| 占位符 | 含义 | 示例 |
|---|---|---|
| `{total_frames}` | 动图总帧数 | `24` |
| `{frame_count}` | 本次抽取的帧数量 | `9` |
| `{frame_indices}` | 抽出的帧序号，从 1 开始 | `2, 5, 8, 11, 14` |
| `{duration}` | 动图总时长（秒） | `1.60` |
| `{output_mode}` | 输出方式 | `grid` |
| `{original_path}` | 原图本地路径（仅开启「附带原图路径」时有值） | `E:\...\a.gif` |

例如填 `动图共 {total_frames} 帧，已抽取第 {frame_indices} 帧`，会得到
`动图共 24 帧，已抽取第 2, 5, 8, 11, 14 帧`。

> 填错名字的占位符会被替换为空，并在插件日志中告警，不会把 `{name}` 原样发给模型。
> 若渲染后只剩下括号、逗号之类的符号，该句会被直接丢弃，不会产生空说明。

## 原图路径（可选）

开启「附带原图路径」后，插件会把原始图片在本地的路径作为文本一并交给模型，
方便它对该文件做后续操作。

- **不会额外占用磁盘**：直接复用 AstrBot 已经保存的图片文件，插件不复制。
- **仅当前轮次有效**：AstrBot 会在消息处理结束后立即清理这些临时文件。

> 插件自身**不提供持久化**，也不会在自己的数据目录里缓存任何图片。
> 抽帧产生的图片同样放在 AstrBot 的临时目录，交由框架统一清理。
> 如需跨轮次使用同一张图片，请自行将文件另存到其他位置。

## 配置说明

配置项分为四组：

- **启用插件** —— 总开关
- **Markdown 内嵌图还原** —— 域名白名单、超时、大小上限、占位文本、是否处理引用消息
- **动图抽帧** —— 抽帧参数、输出方式、单帧尺寸、抽帧说明文本、原图路径相关选项
- **单条消息新增图片上限** —— 护栏，限制插件在一条消息里最多新增多少张图片

「单条消息新增图片上限」用于避免多个动图叠加产生过多图片：一条消息里若包含 3 个动图，
每个抽 4 帧，就会产生 12 张图，足以超出很多模型或服务的限制。

> 注意：达到上限后，剩余的图会**保持原样**（插件不会删除消息里已有的图片），
> 因此最终图片总数可能超过该上限。这是为了避免丢图。

## 行为说明

- 插件改写的是**消息链本身**，因此在它之后运行的插件也能看到还原后的图片。
- 插件会在其他插件**之前**处理图片。
- 群聊中只有**被 @ 或符合唤醒条件**的消息才会处理，普通聊天消息不会被影响。
- 若你配置了**域名白名单**，只有白名单内域名的图片会被下载。留空表示不限制。

## 依赖

- AstrBot 内置的 Pillow

## 已知限制

- 原图路径只对当前这一轮对话有效，这是 AstrBot 临时文件的生命周期决定的。
  插件不提供持久化，需要跨轮次请自行另存文件。
- 动图抽帧按**帧序号**取样，不考虑每帧的实际播放时长。若动图各帧延迟差异很大，
  抽出的帧在时间上可能不均匀。
